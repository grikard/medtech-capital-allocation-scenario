# The Elena Scenario — Medtech Capital Allocation

Visual executive scenario for enterprise medtech AI capital allocation.

## Purpose

This artifact shows how an enterprise medtech CFO could reallocate an $80M commercial AI capital plan across the four Workflow Economics postures:

- Automate Now
- Sequence Next
- Build & Defend
- Protect & Invest

It is designed as a board-level visual companion to the medtech capital equipment cycle-compression article.

## Live Version

https://grikard.github.io/medtech-capital-allocation-scenario/

## Core Thesis

A uniform AI budget misprices enterprise AI because workflows sit on different displacement curves.

The correct allocation model separates:

| Posture | Role in Capital Plan |
|---|---|
| **Automate Now** | Deploy where the displacement ratio already exceeds 1.0 |
| **Sequence Next** | Fund evals, instrumentation, and infrastructure where the threshold is approaching |
| **Build & Defend** | Build proprietary data moats in workflows where customer and contract history matter |
| **Protect & Invest** | Preserve human judgment where error cost and signal threshold remain high |
